Dataset Selection Report
Selected Dataset

For Week 3 of PRT681, I selected the Northern Territory Bore Locations, Water Quality and Groundwater Levels dataset from the Northern Territory Government Open Data Portal.

I selected this dataset because it is directly related to the Northern Territory and provides both geographical and environmental data that can be used for SQL Server analysis.

Dataset Size

The dataset contains three main parts:

Bores: 43,225 records
Groundwater Levels: 2,405 records
Water Quality: 84,769 records

This gives approximately 130,399 records in total, which provides enough data for meaningful database queries and analysis.

Main Data

The dataset contains information such as:

Bore number and name
Bore status and purpose
Bore depth and yield
Water levels
Water-quality measurements
pH, TDS, salinity and other chemical measurements
Sample dates
Latitude and longitude
UTM coordinates
Groundwater monitoring information
Why I Selected This Dataset

I chose this dataset because it provides more variety and depth than a small dataset such as mobile or cell coverage data. It also contains three related datasets, which makes it suitable for demonstrating database relationships and SQL queries.

The geographical information is particularly useful because the locations of the bores can be mapped across the Northern Territory. The dates and water-quality measurements also allow trends and comparisons to be analysed over time.

Another reason for choosing this dataset is that groundwater is an important environmental resource in the Northern Territory. Therefore, the dataset has a clear real-world purpose rather than being only a theoretical dataset.

Potential Analysis

Using SQL Server, I can analyse questions such as:

How many bores are located in different areas of the NT?
Which areas have the most groundwater bores?
What are the average bore depths and yields?
How does water quality vary between locations?
What are the trends in water-quality measurements over time?
Which bores have high levels of TDS, salinity or other measurements?

The data can also later be connected to Power BI to create maps, charts and dashboards.

Conclusion

I believe the NT groundwater dataset is a strong choice for PRT681 Week 3 because it is large, geographically relevant, contains multiple related datasets, and provides enough information for SQL Server and data visualisation activities. It also gives me an opportunity to work with a real-world Northern Territory dataset rather than a common generic dataset.

Source: Northern Territory Government Open Data Portal – Northern Territory Bore Locations, Water Quality and Groundwater Levels.
