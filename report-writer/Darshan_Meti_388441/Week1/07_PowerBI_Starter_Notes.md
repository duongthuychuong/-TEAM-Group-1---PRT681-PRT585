# Power BI Starter Notes - Week 1

## What Power BI is
Power BI is a business intelligence and reporting platform used to connect to data, transform it, model relationships, create calculations and build interactive visuals.

## Basic workflow
**Data Source → Power Query → Data Model → DAX → Visuals → Report**

## First concepts reviewed
- Get Data
- Fields / columns
- Report canvas
- Visualisations pane
- Filters
- Basic charts and cards

## Key learning
A useful dashboard starts with a business question, not with a chart.

Example questions:
1. What is total sales?
2. Which product has the highest sales?
3. Which region is underperforming?
4. How are sales changing by month?
