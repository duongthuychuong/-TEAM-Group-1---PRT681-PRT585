# Week 2 - Power BI Practice Log

## Practice objective
Continue learning report-building basics and connect visuals to stakeholder questions.

## Tasks practised
- Import a small sales dataset.
- Check column names and data types.
- Create a Card for Total Sales.
- Create a column chart for Sales by Product.
- Create a bar chart for Sales by Region.
- Add a slicer for Region.
- Test how selections filter the page.

## Business questions used
1. What are total sales?
2. Which product contributes the most sales?
3. Which region has the strongest performance?
4. Can a user filter results by region?

## Learning point
A visual should have a reason to exist. Each visual should answer a business question clearly.
