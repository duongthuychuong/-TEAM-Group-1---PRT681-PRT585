# SSRS Basics - Week 4

## What SSRS is
SQL Server Reporting Services (SSRS) is used to build structured, paginated reports that are suitable for printing, PDF/Excel export and scheduled distribution.

## Typical SSRS components
- Data source
- Dataset
- Parameters
- Table / Matrix
- Expressions
- Headers and footers
- Export to PDF / Excel

## Power BI vs SSRS
- **Power BI:** interactive exploration, dashboards, filtering and visual analysis.
- **SSRS:** fixed-layout operational or management reports, often detailed and printable.

## Example SSRS report
Monthly Sales Report
- Parameter: Month
- Parameter: Region
- Table: Order detail
- Summary: Total Sales, Total Profit, Order Count
