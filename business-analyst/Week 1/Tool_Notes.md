# Week 1 — Tool and Technique Notes

These concise notes support interview preparation. They explain selected tools without claiming mastery or course completion.

## Business Analyst tools

### BPMN 2.0

BPMN is a standard visual language for business processes. It uses events, activities, gateways and flows so business and technical stakeholders can discuss the same process. Common use cases include current-state analysis, future-state design and delivery handover. In CareerTrack NT, a gateway separates a valid application from one that must return to the user for correction.

### Jira

Jira is a work-management tool often used for product backlogs, stories, defects and sprint boards. It helps teams see ownership, priority, acceptance criteria and delivery status. A common use case is backlog refinement before sprint planning. A CareerTrack NT story could move from `To Do` to `In Progress`, `Review` and `Done` only when its acceptance criteria are met.

### Confluence

Confluence is a collaborative documentation platform. Teams use it for requirements, decisions, meeting notes, process information and links that should remain discoverable. It complements Jira: Jira tracks the work while Confluence explains context. A CareerTrack NT page could hold the glossary and link to the implementation stories.

### Figma and wireframing

Figma is a collaborative interface-design tool used for wireframes and prototypes. Wireframes test information structure and flows before expensive implementation begins. They support stakeholder feedback and expose missing requirements. A low-fidelity CareerTrack NT screen shows the application form, status filters and results table without prescribing final branding.

### SQL

SQL is the language used to define, query and modify relational data. A BA uses it to investigate data, validate reports and make rules more precise. Common operations include `SELECT`, joins and aggregates. In CareerTrack NT analysis, SQL can confirm how many applications exist at each stage.

### Requirements traceability

Traceability connects business needs to requirements, stories, designs and tests. It helps identify missing coverage and assess the impact of change. It is especially valuable in regulated or complex projects. The CareerTrack NT matrix links each requirement to an endpoint, screen element and UAT test.

### User acceptance testing

UAT is business-led confirmation that a solution supports agreed real-world needs. It evaluates business outcomes in representative scenarios. UAT cases define preconditions, steps and expected results. One CareerTrack NT case confirms that a follow-up date earlier than the application date is rejected clearly.

### Agile/Scrum and backlog refinement

Agile delivery uses short feedback cycles and adapts as evidence emerges. Scrum provides roles, events and artefacts such as the product backlog and sprint review. Refinement clarifies, splits, estimates and reorders upcoming work. It is not a status meeting; the output should be stories ready enough for the team to select.
